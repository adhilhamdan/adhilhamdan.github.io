# adhilhamdan.github.io

Personal portfolio site for Adhil Hamdan — VLSI Engineer & MS Applicant.

Built with React + Vite + Tailwind CSS. Hosted on GitHub Pages.

## Stack
- React 18
- Vite 5
- Tailwind CSS 3
- Framer Motion
- GitHub REST API (live project data)

## Local dev
```bash
npm install
npm run dev
```

## Deploy to GitHub Pages
```bash
npm run deploy
```

This runs `vite build` and pushes the `dist/` folder to the `gh-pages` branch.

## Adding resume
Drop `resume.pdf` into the `public/` folder before building.
